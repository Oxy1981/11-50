🎨 Вступ до CSS

1. Поняття CSS та каскадності

CSS (Cascading Style Sheets — каскадні таблиці стилів) — спеціальна мова для опису зовнішнього вигляду та форматування веб-сторінок, написаних мовою розмітки.

Головна ідея: HTML відповідає за зміст і логічну структуру документа, а CSS — за його візуальне оформлення та позиціонування елементів.

Каскадність означає, що до одного елемента може застосовуватися кілька правил із різних джерел. У разі конфлікту браузер застосує їх «каскадом» відповідно до системи пріоритетів.

2. Синтаксис CSS-правила

Правило складається з селектора (вказує, до якого елемента застосовується стиль) та блоку оголошень у фігурних дужках { ... }, де через крапку з комою перелічуються пари властивість: значення;

p {
    font-size: 20pt;
    color: green;
    font-family: Arial, sans-serif;
}

Коментарі у CSS записуються між символами /* та */.

3. Способи підключення CSS до HTML

СпосібСинтаксис і місцеОсобливості
1. Вбудований стиль (Inline Styles)Безпосередньо у відкриваючому тегу, атрибут style:
<p style="color: red; font-size: 18px;">Текст</p>
Найвищий пріоритет. Лише як виняток для точкового оформлення одного унікального елемента. Змішує вміст і дизайн, ускладнює редагування.
2. Внутрішня таблиця стилів (Embedded)У розділі <head> всередині парного тегу <style> ... </style>.Діє лише в межах однієї сторінки. Зручно для односторінкових сайтів або тестування макета.
3. Зовнішня таблиця стилів (External)Окремий файл з розширенням .css, підключається в <head> тегом <link>:
<link rel="stylesheet"
 href="css/style.css">
Найпоширеніший і рекомендований стандарт. Один CSS-файл керує дизайном десятків сторінок одночасно, пришвидшує завантаження й спрощує підтримку коду.

Додатково: директива @import url("style.css"); всередині тегу <style> використовується рідше через уповільнення завантаження сторінки.

4. Базова пріоритетність (каскад)

Якщо до одного елемента задано суперечливі стилі, діє правило пріоритетів (від найвищого до найнижчого):

  1. Вбудовані стилі (атрибут style у тезі).
  2. Внутрішні та зовнішні таблиці стилів (перемагає правило, яке підключене або записане в коді нижче).
  3. Стилі браузера за замовчуванням.
